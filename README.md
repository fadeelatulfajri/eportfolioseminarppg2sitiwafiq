## 🎨 Bahasa Desain & Visual (Framer-Portfolio Aesthetic)
E-portofolio ini dibangun dengan gaya visual **Minimalist Tech / Framer-Portfolio Aesthetic**, mengedepankan hierarki visual modern, white space yang luas, kartu interaktif bernomor, dan badge/pill tags yang elegan:

1. **Latar Belakang & Tekstur:**
   - Subtle Dot Grid Matrix (`bg-dot-grid` & `bg-dot-grid-dense`).
   - Section rhythm lembut: Pure White (`#FFFFFF`) & Light Slate Gray (`#F8F9FA`).
2. **Orbital Profile Radar:**
   - Foto profil Siti Wafiq dalam bingkai lingkaran bergaris orbit putus-putus (*dashed concentric rings*).
   - Floating role pills mengorbit halus (*Guru PPKn, Sosial-Emosional, Kepemimpinan, Pendidik Reflektif, Change Maker*).
3. **Tilted Polaroid Stack:**
   - Tumpukan foto polaroid 3 dimensi yang menyebar halus saat kursor didekatkan (*fan/hover effect*), memotret kebersamaan dengan murid SMPN 8 Purwokerto dan momen wisuda.
4. **Tipografi & Tombol:**
   - Display font: **Plus Jakarta Sans** (tebal & tight kerning), body text: **Inter**, kutipan editorial: **Newsreader**, dan badge: **JetBrains Mono**.
   - Tombol kapsul hitam pekat dengan ikon panah melingkar (`btn-capsule`).

## ⚡ Fitur Interaktif Unggulan
- **Interactive 4C Model Switcher:** Penguji dapat melihat keempat refleksi sekaligus atau memfilter satu per satu (Connection / Challenge / Concept / Change).
- **STOP Technique Micro-Simulator:** Interaksi klik ritual STOP (Stop, Take a Breath, Observe, Proceed) untuk manajemen emosi di kelas PPKn.
- **BAGJA Interactive Cycle:** Menelusuri 5 tahapan inkuiri apresiatif pada projek kepemimpinan secara dinamis.
- **Instant Google Drive Modal Reader:** Tampilan preview dokumen terintegrasi langsung di layar tanpa mengganggu navigasi portofolio.
- **Interactive Image Lightbox:** Klik sembarang foto untuk memperbesar tampilan resolusi tinggi disertai keterangan konteks lapangan.
- **Command Palette (`Ctrl+K`):** Pencarian kilat untuk langsung melompat ke bagian mata kuliah atau artefak tertentu.
- **Progress Bar & Dynamic Back to Top:** Indikator persentase scroll real-time di bagian atas dan tombol kembali ke atas.
- **Print Optimization (`@media print`):** Tampilan otomatis bersih dan rapi saat diekspor menjadi dokumen PDF atau dicetak.

## 🚀 Cara Menjalankan Portofolio
1. **Langsung Buka File:**
   - Cukup klik ganda file `index.html` pada File Explorer, atau drag file ke browser pilihan (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
2. **Menggunakan Live Server / Localhost:**
   ```bash
   # Menggunakan Python
   python -m http.server 8000
   
   # Atau menggunakan Node npx
   npx serve .
   ```
   Lalu buka browser di `http://localhost:8000`.
